# Автотесты для Stellar Burgers

Автоматизированные тесты для веб-приложения Stellar Burgers с использованием Selenium и pytest.

## Функциональность

Проверяемые сценарии:
* Регистрация (успешная и с ошибкой пароля)
* Вход разными способами (с главной, из личного кабинета, с форм регистрации и восстановления пароля)
* Навигация по приложению (личный кабинет, конструктор, логотип)
* Выход из аккаунта
* Работа с конструктором бургеров (вкладки «Булки», «Соусы», «Начинки»)

## Запуск тестов

1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите тесты: `pytest`

Примечание: выбор браузера (Chrome/Firefox) задаётся параметризацией
в `conftest.py` через фикстуру `browser_type`.

## Структура проекта

* `tests/` — все тестовые сценарии
* `conftest.py` — фикстуры (`driver`, `registered_user`, `logged_in_user`)
* `constants.py` — URL-адреса страниц (файл констант)
* `helpers.py` — вспомогательные функции (генераторы данных, работа с модальным окном, вход)
* `locators.py` — локаторы элементов
* `requirements.txt` — зависимости
